## Diretrizes de adaptação

- A página de Estratégia é específica dessa experiência e não deve ser aplicada como layout universal.
- Use os nomes oficiais de `src/lib/strategy-allocation.ts`: “Renda fixa”, “Ações e BDRs”, “ETFs internacionais” e “Fundos imobiliários (FIIs)”.
- O editor permite percentual zero, calcula o total e oferece “Distribuir restante”. Preserve esses comportamentos e os estados de dados incompletos.
- Não implemente rendimento esperado, risco, patrimônio projetado, histórico de desempenho, abas adicionais ou decisões de investimento por causa das imagens.
- As propostas são referências desktop geradas por IA, não capturas da aplicação. Não foram geradas imagens mobile nem feita comparação em navegador; a responsividade continua sendo requisito do código.

A versão anterior de `page-desktop.png`, com identidade verde e rótulos históricos, foi aprovada pelo usuário. A imagem foi substituída nesta atualização; essa aprovação pertence à versão anterior e não significa aprovação das novas propostas.
