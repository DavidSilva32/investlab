# Identidade visual do InvestLab

## Referência

[`InvestLab Branding Dashboard Mockup.png`](./InvestLab%20Branding%20Dashboard%20Mockup.png) é a referência de identidade visual aprovada pelo pedido atual. Ela apresenta o logo completo com símbolo de barras azuis crescentes e seta ascendente, o nome InvestLab, o símbolo isolado e uma versão reduzida para favicon. Também mostra variações em fundos escuro, claro e azul.

O mockup serve como referência visual da marca e de seu uso no menu lateral e na aba do navegador. Não é uma captura da aplicação, nem deve ser usada como arquivo de logo. Os elementos da identidade são vetoriais e mantidos nos recursos próprios do projeto.

## Aplicação e temas

- O logo completo aparece no shell da aplicação, junto ao menu principal.
- A variante de símbolo isolado pode ser usada em espaços compactos, incluindo o favicon.
- No tema escuro, o wordmark mantém contraste claro; no tema claro, usa contraste escuro. O símbolo preserva os tons azuis da identidade.
- O mockup mostra fundos coloridos como variações de apresentação da marca, não como alteração dos tokens ou superfícies da aplicação.
