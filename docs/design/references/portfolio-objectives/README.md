## Tokens e adaptação

- Use `destination-reserve` (azul), `destination-personal` (roxo), `destination-long-term` (verde), `destination-purpose-unknown` (amarelo) e `destination-unassigned` (neutro) somente para finalidades/destinos.
- Use cores de classe apenas quando a classe estiver identificada; não transforme finalidade em classe de ativo.
- As imagens são somente desktop. Mantenha a responsividade no código; nenhuma imagem mobile foi gerada e nenhuma captura de navegador foi feita.
- Preserve os estados de exclusividade, confirmação, persistência, dados ausentes e limitações descritos pelos componentes ativos.
