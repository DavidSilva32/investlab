SEM TERMOS COMPLICADOS

O que é essa conexão?

É uma ponte segura entre o InvestLab e um assistente de IA. Você faz uma pergunta; o assistente busca somente as informações autorizadas e explica a resposta.

1

Você pergunta

Por exemplo: “Como estão meus objetivos?”

2

Você autoriza

Entre na sua conta InvestLab e confira o acesso pedido.

3

Recebe uma resposta

O assistente consulta os dados permitidos da sua conta.

✓
Você mantém o controle

A conexão é somente para consulta. Ela não cadastra, altera ou exclui informações no InvestLab.

Quer configurar agora? Abra “Conectar ao ChatGPT” no menu. O guia reúne os passos, os dados para copiar e o ícone do InvestLab no mesmo lugar.
