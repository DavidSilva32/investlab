# Ilustrações do curso de FIIs — Issue #265

## Uso

Ilustrações genéricas para `/aprender`, nas aulas sobre exemplos de imóveis e operações que FIIs podem deter. Arquivos: `shopping-center.webp`, `logistics-warehouse.webp` e `residential-building.webp`.

As imagens foram geradas por IA para fins educativos. Não representam fundos, imóveis, empreendimentos, rendimentos nem oportunidades reais. A classe usa o nome oficial `Fundos imobiliários (FIIs)` e o token semântico `--asset-class-fiis`, conforme `src/lib/strategy-allocation.ts` e `src/app/globals.css`.

## Prompt set

Gerar três ilustrações editoriais arquitetônicas em paisagem, com aparência semi-realista, composição clara e educativa para adultos: (1) shopping contemporâneo de bairro; (2) centro logístico com docas e caminhões sem marca; (3) edifício residencial de médio porte em bairro urbano brasileiro. Usar superfícies neutras e acentos verdes discretos. Sem logotipos, letreiros legíveis, texto, gráficos, moedas ou promessas de retorno.
